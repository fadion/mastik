# Page briefs

One brief per run, picked by `SKILL.md` Phase 1. Each names a real product so the copy, the
hierarchy and the imagery have something to be about. A new brief should need the same four
passes.

## Pool

1. A landing page for a small coffee roaster that sells subscriptions: hero with a photo,
   three plans, how it works in three steps, testimonials, footer.
2. A settings screen for a team chat app at 1280 wide: sidebar navigation, a profile section with
   an avatar, notification toggles, a danger zone.
3. An analytics dashboard for a bike-sharing city service: KPI tiles, a line chart of rides per
   day, a bar chart by station, a table of stations, a map placeholder.
4. A mobile onboarding flow, three screens at 390 wide, for a language-learning app:
   illustration, title, body, progress dots, primary and secondary buttons.
5. A pricing page for a developer tool: monthly/yearly toggle, three tiers with feature lists, a
   comparison table, FAQ.
6. A recipe page for a cooking magazine: hero photo, ingredients with quantities, numbered steps
   with photos, nutrition facts, related recipes.
7. An event page for a design conference: speakers grid with photos, schedule by day, venue with
   a map placeholder, ticket tiers.
8. An e-commerce product page for a backpack: gallery, colour swatches, size selector, reviews
   with star ratings, "you may also like" row.

## The passes

Every run asks for these in order, as separate requests in one session, as a person would:

1. **The page.** Build the brief as a finished design. Use sections with auto layout, real copy,
   a type scale, a colour palette. Make the palette variables or styles, so later edits reuse
   them, and make components for what repeats.
2. **Photos and icons.** Put photos where the brief needs them, from the run folder's `photos/`
   if it has any, and use the icons a real page needs (navigation, features, social links).
3. **Drawn shapes.** Draw what a template would not give you: a logo mark, a decorative wave or
   blob behind a section, a custom divider, a chart annotation arrow. Use paths, boolean
   operations and strokes.
4. **Finish.** Add effects (shadows on cards, a blur behind a sticky header, a gradient overlay on
   the hero photo), check the contrast, line things up, and export a PNG of the page to look at
   it.
